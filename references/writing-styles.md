# 写作风格模板库

## 模板 A：观点/分析型（道法类、政策解读类）

适用于：政策解读、教育趋势分析、观点评论

### 标题公式
- 数字 + 反差：「2026中考改革3大变化，第一条就颠覆认知」
- 疑问句：「双减三年后，鸡娃的家长都去哪了？」
- 归属感：「写给焦虑的中考家长：这5件事现在知道还不晚」

### 开篇结构
```
场景切入（200字）→ 核心问题抛出（100字）

场景：具体到某个家长/孩子的真实困境
问题：上升到普遍性困惑
```

### 正文结构
```
H2「现象」：现状描述 + 数据/政策原文
H2「分析」：为什么会出现这种现象（引用权威）
H2「对策」：家长/学生可以怎么做（具体可操作）
```

### 结尾结构
```
总结观点（100字）→ 金句收尾（50字）→ CTA（50字）
```

## 模板 B：故事/育儿型

适用于：亲子日常、育儿反思、成长故事

### 标题公式
- 画面感：「昨晚陪儿子写作业到11点，我决定不卷了」
- 反转：「我一直以为儿子不爱学习，直到我做了这件事」
- 共鸣：「你还在催孩子写作业？其实你错了」

### 开篇结构
```
具体场景（300字）→ 内心独白（100字）

场景：时间/地点/人物/对话
独白：当时的困惑/焦虑/感悟
```

### 正文结构
```
H2「冲突」：发生了什么矛盾
H2「行动」：我做了什么改变
H2「反思」：从这件事学到了什么
```

### 结尾结构
```
感悟升华（150字）→ 金句收尾（50字）→ CTA（50字）
```

## 模板 C：干货/攻略型

适用于：学习方法、备考攻略、资源推荐

### 标题公式
- 数字 + 承诺：「3个方法让孩子英语从60分到90分」
- 痛点 + 方案：「孩子总粗心？用这5步改掉坏习惯」
- 清单式：「初二寒假必做的4件事（附时间表）」

### 开篇结构
```
痛点共鸣（150字）→ 效果承诺（50字）

痛点：描述读者的困扰
承诺：看完这篇文章能解决什么问题
```

### 正文结构
```
按步骤/要点展开，每步包含：
Step 1「是什么」
    - 这个方法的定义/原理
    - 为什么有效
Step 2「怎么做」
    - 具体操作步骤
    - 常见错误
Step 3「案例」
    - 实际效果
    - 家长反馈
```

### 避坑提醒
```
⚠️ 常见误区1
⚠️ 常见误区2
⚠️ 常见误区3
```

### 结尾结构
```
总结清单（100字）→ 互动话题（50字）→ CTA（50字）
```

## 写作节奏规则

1. **段落控制**：每段不超过 5 行，3 行最佳
2. **短句优先**：每句不超过 30 字
3. **段落间空行**：视觉上制造呼吸感
4. **加粗重点**：每个 H2 下 1-2 个关键词句加粗
5. **引用格式**：金句/政策原文用 `>` 引用格式
6. **列表使用**：3 条以上就用编号/无序列表
7. **图片分隔**：每 800-1000 字插一张图
