# CTA 话术模板库

## 引导关注类

```
如果你也在关注孩子的教育，欢迎关注「趴爹育儿圈」，每天分享AI时代的育儿思考。

---

你对这个话题有什么看法？欢迎在评论区留言讨论，我会一一回复。

---

更多教育资源和方法，关注公众号回复【关键词】获取。
```

## 引导进群类

```
想和更多家长一起交流备考方法？加我微信 xxx，备注「中考」，拉你进群。

---

一个人焦虑不如一群人同行，扫码加入我们的家长交流群。
```

## 引导转发类

```
如果你觉得这篇文章有帮助，请转发给需要的人。让更多家长看到。

---

点击「在看」和「分享」，帮助更多焦虑的家长找到方向。
```

## 引导互动类

```
你家孩子有类似的情况吗？你是怎么处理的？留言区聊聊。

---

你觉得这3个方法哪个最实用？投票告诉我。
```

## 引导收藏类

```
干货太多记不住？先收藏，慢慢看。

---

建议收藏+转发，方便随时查阅。
```

## 组合模板

```
【关注型 + 互动型】

你觉得呢？欢迎在评论区说说你的看法。
如果觉得有道理，关注「趴爹育儿圈」，我们慢慢聊。
```

```
【转发型 + 进群型】

如果这篇文章对你有帮助，帮忙点个「在看」。
想进家长群交流，加我微信 xxx。
```

```
【收藏型 + 分享型】

先收藏，下次看。
也欢迎分享给身边需要的朋友。
```

## CTA 设计原则

1. **一篇文章一个核心CTA** — 不要同时让人关注+加群+转发
2. **CTA 放在结尾，短而有力**
3. **给读者一个理由** — "帮助更多家长"比"帮我转发"好
4. **CTA 前要有铺垫** — 先给出价值，再提请求
5. **用第一人称** — "想和我一起..." 优于 "请关注该公众号"

## CTA 位置

```
正文结束（文章最后一段）

金句（单独一段）
↓
价值总结（1-2句）
↓
CTA（1句）
↓
署名/公众号ID
```
